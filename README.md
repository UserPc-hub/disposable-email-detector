# Disposable Email Detector API

A fast and reliable API that detects disposable, temporary, and fake email addresses. It helps developers prevent spam, fake signups, and fraudulent accounts.

## Features

- **Fast**: Returns results in milliseconds.
- **Accurate**: Database of 160,000+ known disposable domains, updated daily.
- **Easy to integrate**: Simple GET request with one parameter (`email`).
- **Free tier available**: Test it without paying.
